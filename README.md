## 闽南 · 潮汕下南洋（子专题）

> An interactive map of Minnan–Chaoshan (Hokkien/Teochew) migration waves to Southeast Asia, 1684–1949.

一份基于文史档案构建的**时间轴驱动**可视化：拖动底部年份滑块，从 1684 年海禁初开到 1949 年离散潮暂歇，地图上**闽南（厦门、泉州湾、漳州海道示意）与粤东潮汕各港**同步向曼谷、新加坡、槟城、巴达维亚、西贡、金边等地投射迁徙弧线，左右面板串联五阶段叙事、年度事件与陈慈黉、张弼士、郑智勇等侨领故事。

## 主要功能

- **动态迁徙地图**：MapLibre／MapBox 矢量底图，海岸线历史航线结点与闽粤分枝弧线
- **时间轴**：1684–1949 年拖动与倍速播放
- **五色阶段图例**：对应海禁初开、红头船鼎盛、开埠契约工、民国高峰、战乱终结
- **累计人次示意**：弧线数据含潮汕口岸统计与闽南口岸并列估算分支（见数据来源说明）
- **事件与华侨群像**：清廷开海、「猪仔贸易」合法性、槟城与新山沿革、抗战筹赈等

## 数据来源（节选）

- 《汕头海关志》：1864–1911 仅从汕头口岸核销出境约二百九十四万人次（潮籍为主，亦含毗邻过境者）
- 《厦门海关历史档案》与近代条约史：**厦门口岸**在五口通商后与汕头并列为南洋华工出海枢纽
- 樟林古港 / 澄海县志：1822–1858 樟林港赴暹罗潮人实证约八十八万人次
- 维基百科「下南洋」、闽南与潮汕族群专题
- 广东省侨办、圭海四记《南洋华侨华人五大帮人口考》、泰国潮州会馆等处人口参考

弧线 `volume` 为**分项示意人次**，目的在于呈现闽南与潮汕两大方言群并列下南洋的视觉权重，并非单一行政关口的重复核算结果。

## 运行

```bash
npm install
cp .env.example .env   # 可选：填入 MapBox token；留空则用 MapLibre + OSM
npm run dev
npm run build
```

## 技术栈

| 类别 | 选型 |
| --- | --- |
| 框架 | Vite + React 18 + TypeScript |
| 地图 | Mapbox GL JS v3 / MapLibre GL JS v4（fallback） |
| 状态 | Zustand |
| 可视化 | D3.js（大圆弧 + 插值） |
| 动效 | Framer Motion + `requestAnimationFrame` 粒子 |
| 样式 | Tailwind CSS + 思源宋体（潮汕红 / 闽南青 / 米黄配色意象） |
