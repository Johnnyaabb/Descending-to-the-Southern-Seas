## 2. 视觉与设计体系（建议保留格式，可改色名与色值）

当前站点通过 **Tailwind 扩展色** + **`.panel` 毛玻璃卡片** 统一风格。新主题可换色，但建议保留「深色底 + 主色 accent + 米白字」层级。

### 2.1 品牌色（`tailwind.config.js` → `theme.extend.colors`）

| Token | 当前值 | 新主题建议 |
| --- | --- | --- |
| `chaored` | `#b22222` | 主强调色（按钮、滑块强调、事件策略类） |
| `oldgold` | `#c8a951` | 次要强调（年份、装饰线、阶段标签） |
| `ricepaper` | `#f5e6c8` | 主文字色 |
| `searoyal` | `#1e3a8a` | 可选用海蓝辅助 |
| `seafoam` | `#0e7490` | 可选用青绿辅助 |
| `ink` | `#1a1a1a` | 深色块 |

阶段条、迁徙弧线等**阶段色**在数据里以 **hex** 写在 `phases` 中，不依赖上述 token。

### 2.2 字体

| 用途 | 当前配置 |
| --- | --- |
| 标题/年号感 | `Noto Serif SC` / `Songti SC`（`.font-display`） |
| 正文/UI | `Noto Sans SC` |

新主题若换字体，请同步 `index.html` 引入与 `tailwind.config.js` 的 `fontFamily`。

### 2.3 全局组件类名（`globals.css`）

- **`.panel`**：`bg-black/55`、`backdrop-blur-md`、`border-oldgold/30`、`rounded-lg`、`shadow-scroll` — 左侧叙事、右侧统计/图例、底部时间轴外框均使用。
- **地图 Popup**：深色底 + 金边 + 思源系（与主 UI 一致）。
- **时间轴滑块 `.cs-slider`**：隐形轨道 + 圆形拇指；换主题时可只改拇指/光晕颜色。

### 2.4 页面背景

- 全屏渐变：`from-[#0a0a0f] via-[#0e1116] to-[#0a0a0a]`（可在 `App.tsx` 中替换为与主题相符的渐变）。

## 3. 页面信息架构（布局保持不变）

以下为 **当前实现顺序**，新主题应维持该结构，仅替换文案与数据。

```
┌─────────────────────────────────────────────────────────────┐
│ Header：主标题 · 副标题 · 快捷键提示 · 地图样式切换(可选) · 链接 │
├──────────────┬──────────────────────────────┬─────────────────┤
│ 左栏          │         全屏地图              │ 右栏            │
│ · 阶段头图    │  Mapbox / MapLibre           │ · 累计统计      │
│ · 阶段叙事    │  + 迁徙弧线/粒子/港口标记     │ · 人物卡片      │
│ · 要点列表    │  + 历史事件标记 Popup         │ · 图例          │
│ · 本阶段事件  │                              │                 │
│ · 史料来源    │                              │                 │
├──────────────┴──────────────────────────────┴─────────────────┤
│ Footer：时间轴面板（播放/重置/倍速/当前阶段条/年份/事件圆点）      │
└─────────────────────────────────────────────────────────────────┘
```

### 3.1 左栏叙事面板（`NarrativePanel`）

- 随 **当前年份** 所在 `phase` 切换。
- 区块：**阶段标题区（带阶段色渐变底）** → **长叙事** → **要点列表** → **本阶段关键事件（可点击，联动地图选中年份与事件）** → **史料来源**。
- 高度：随 `main` 区域约束，**内部滚动**（勿用固定 `100vh` 减常量，避免与底栏重叠）。

### 3.2 底部时间轴（`TimeSlider`）

- **时间范围**与数据 `TIMELINE_MIN / MAX` 一致。
- **五色阶段带**：宽度按各 `phase` 年份跨度比例分配；点击可跳到阶段起点。
- **播放 / 暂停 / 重置 / 倍速**；键盘 ← → 年、空格播放。
- **事件圆点**：落在**彩色滑轨条**上，点击设定年份并选中事件。
- **当前阶段**胶囊与 **大号年份** 显示。

### 3.3 右栏

- **统计计数器**：随时间累积的某种指标（人数、里程、贸易额等，由数据驱动）。
- **代表性人物卡片**：头像区、姓名、年份、简介；「聚焦」可 `flyTo` 目的地并设年份。
- **图例**：阶段色说明 + 可选补充统计块。

### 3.4 地图层

- **港口/节点标记**（起点、终点）。
- **迁徙流**（大圆弧 + 动画粒子或等价动效）。
- **历史事件标记**：分类颜色（如 policy / war / economic / settlement），点击与左栏/时间轴联动。

## 4. 数据模块清单（请为每个文件准备同结构数据）

当前代码以 **TypeScript 常量** 放在 `src/data/`。新主题请按表复制结构并改名内容。

| 文件 | 作用 | 核心字段 |
| --- | --- | --- |
| `phases.ts` | 时间阶段划分 | `id`, `startYear`, `endYear`, `title`, `subtitle`, `color`, `narrative`, `highlights[]`, `source` |
| `events.ts` | 地图可标历史事件 | `id`, `year`, `title`, `location`, `coord`, `summary`, `detail`, `source`, `category` |
| `ports.ts` | 港口/城市节点 | `id`, `name`, `nameEn`, `kind`（origin/destination）, `country`, `coord`, `description`, `source`, … |
| `flows.ts` | 迁徙流 | 与弧线路径、粒子或流量相关（按现有类型复制） |
| `people.ts` | 右侧人物 | 与 `destinationId`、`emigrateYear` 等字段对齐港口 `id` |
| `populations.ts` | 图例或快照数据 | 国家/地区 + 数值等 |
| 其他（如 `seaRoutes.ts`） | 若新主题需要航线/辅助线 | 保持类型安全即可 |

**注意：**

- 同一年多事件时，时间轴自动选中逻辑需在业务上约定（当前实现对「同年多事件」有专门处理思路）。
- 所有展示文案尽量带 **`source`** 便于底部引用。

## 7. 新主题内容工作表（建议打印出来填空）

### 7.1 阶段 `PHASES`

对每一阶段填写：

1. `id`（英文 slug）
2. `startYear` / `endYear`
3. `title` / `subtitle`
4. `color`（hex，用于时间条与弧线）
5. `narrative`（一段）
6. `highlights`（3–8 条短句）
7. `source`

### 7.2 事件 `EVENTS`

每条：

1. `year`、`title`、`location`
2. `coord`：`[lng, lat]`
3. `summary`（列表用）、`detail`（Popup 用）
4. `category`：`policy` | `war` | `economic` | `settlement`（或扩展枚举并同步 `EventMarkers` 配色）
5. `source`

### 7.3 节点 `PORTS`

每个港口/城市：

1. `id`（被 `people`、`flows` 引用）
2. `name` / `nameEn` / `country`
3. `coord`
4. `kind`：出发地或目的地
5. `description`、`source`

### 7.4 人物 `people`

每位：

1. 与现有字段一致（姓名、叙事、`emigrateYear`、`destinationId` 等）
2. 确保 `destinationId` 存在于 `ports`
